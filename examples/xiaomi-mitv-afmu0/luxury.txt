# Luxury TV: the "luxury and light" list for the Xiaomi TV Box S 3rd gen (MiTV-AFMU0, twilight),
# Google TV on Android 14. Tested on this box: Home, apps, screensaver, remote and phone remote all work.
#
# Everything here is DISABLED for user 0, never uninstalled. Undo any line with:
#   adb shell pm enable --user 0 <package>
# A few may vanish from the user after disabling (the system removes them); bring those back with:
#   adb shell cmd package install-existing <package>   then   adb shell pm enable --user 0 <package>
#
# Apply:  tools\debloat.ps1 <ip> examples\xiaomi-mitv-afmu0\luxury.txt
# Undo:   tools\debloat.ps1 <ip> examples\xiaomi-mitv-afmu0\luxury.txt -Undo
#
# Before you start:
# - Install Luxury TV and make it Home first (tools\install.ps1).
# - setupwraith: if Wi-Fi was saved during first setup, forget the network and join it again from Settings,
#   or disabling setupwraith drops Wi-Fi and ADB. Re-enable setupwraith only to pair a new remote.
# - Read every section and delete the lines you want to keep (the voice assistant, an app you watch, Play Store).
# - Never add: com.google.android.gms, com.google.android.gsf, com.google.android.webview,
#   com.google.android.tv.remote.service (phone remote), mitv.service, com.droidlogic*, your keyboard.
